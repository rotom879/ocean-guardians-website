## Project Overview

Ocean Guardians SA is a non-profit organization website focused on marine conservation in South Africa. The website educates visitors about ocean pollution, showcases the organization's impact, and provides ways to get involved.

## Testing Instructions

1. Open index.html in a web browser
2. Resize browser window to test responsiveness:
   - Desktop (>1024px): 4 columns for stats
   - Tablet (768px-1024px): 2 columns for stats
   - Mobile (<767px): 1 column for stats, vertical menu
3. Hover over buttons and cards to see hover effects
